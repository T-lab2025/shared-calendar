# shared-calendar
ゼミの共有カレンダーアプリ開発

## 予定の追加方法
日付のクリック→予定の名前を入れ、OKをクリック→青いアイコンが予定日に追加
## 予定の削除方法
予定のクリック→削除をクリック→青いアイコンが消えれば完了
