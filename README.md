# shared-calendar
ゼミの共有カレンダーアプリ開発

## 予定の追加方法
日付のクリック→予定の名前、時間を入れ、保存をクリック→青いアイコンが予定日に追加
## 予定の削除方法
予定のクリック→削除をクリック→青いアイコンが消えれば完了

## 実行方法

#2. https://t-lab2025.github.io/shared-calendar/にアクセス
